# DuckLocal

<img src="assets/logo.png" width="128" alt="DuckLocal logo">

本地 · 快速 · 简单的 DuckDB 桌面客户端，基于 GPUI Kit 构建。

![DuckLocal 介绍](assets/intro.png)

## 运行

```bash
cargo run
```

## 打包 macOS 应用

```bash
./scripts/bundle.sh
# 生成 target/release/DuckLocal.app
```
