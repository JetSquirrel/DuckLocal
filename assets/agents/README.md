# Agent marks

The marks DuckLocal draws as an AI agent's avatar, on the comments it writes
and on the dashboards it works on. Each is drawn as a single-colour glyph on
the agent's brand colour (`src/ui/agent_avatar.rs`); titles, sizes and fills
were stripped from the originals.
